# Changelog

## 0.2.3 — current source

- Added OpenCode engine management in Settings. The bundled engine and TypeScript client remain pinned to 2.3.0. OpenCode 2.3.2 is an additional supported engine, subject to compatibility checks.
- Added checks for npm package signatures and integrity, plus engine switching and rollback.
- Prepared the source tree for its first public publication. Windows release artifacts require separate build and launch verification.

## 0.2.2

- Grouped related tool activity in the conversation timeline and added expandable command output and file changes.
- Updated Markdown presentation, the memory record viewer, and dropdowns.
- See the [activity report](RCF-0.2.2-ACTIVITY-REPORT.md) and [activity groups report](RCF-0.2.2-ACTIVITY-GROUPS-REPORT.md).

- Updated settings, provider selection, Git and permission controls, and task management.
- Added the Conversation Rail for navigating long chats.
- See the [UX report](RCF-0.2.1-UX-REPORT.md) and [Portable first-run report](RCF-0.2.1-PORTABLE-FIRST-RUN-REPORT.md) for historical verification and limitations.
