# RCF 0.2.1 — проверка первого запуска Portable

Дата: 18 ноября 2026 года

## Изоляция

Проверен код `RCF_DATA_DIR`/`FORGE_DATA_DIR`: Electron направляет `userData` в заданный каталог, OpenCode получает отдельные XDG-пути внутри него. Попытки использовали новые каталоги `.runtime/portable-first-run-*`; переменные с именами ключей/токенов не передавались. Проекты и ключи не открывались. Сборка, установщик и исходники не менялись.

В одной попытке PowerShell не смог переопределить переменную `$HOME` (она зарезервирована), поэтому переменная `USERPROFILE` осталась унаследованной; `RCF_DATA_DIR`, `APPDATA`, `LOCALAPPDATA` и временная папка были направлены в тестовый каталог. Доказательством полной изоляции эта попытка не считается. Изменений пользовательских данных не наблюдалось.

## Проверенные способы запуска и результат

- `child_process.spawn` Portable с минимальным явно заданным окружением и новым `RCF_DATA_DIR`: интерфейс не появился; код завершения `2147483651` (`0x80000003`).
- Повторный `spawn` с расширенным системным окружением и тестовыми каталогами профиля: то же исключение.
- `Start-Process` с тестовыми `APPDATA`, `LOCALAPPDATA`, `TEMP` и профилем: окно ошибки приложения с текстом `unknown software exception (0x80000003)` по адресу `0x00007FF683184BBE`.
- `Start-Process` с обычным окружением и только `RCF_DATA_DIR`/`FORGE_DATA_DIR`: снова появилось окно `Rote Coding Fraktion.exe — Ошибка приложения`.
- Запуск `Start-Process` с тем же тестовым профилем и аргументами CDP, привязанными к `127.0.0.1`: процесс загрузчика завершился, окна приложения и локального CDP-порта не обнаружено.

В одном запуске кратковременно наблюдался процесс `Rote Coding Fraktion` PID 12528; он завершился. Процессы Portable-загрузчиков запускались с PID 25024, 20732, 20560, 21312 и 19308. Связь PID 12528 с родительским процессом проверить не удалось. Ранее существовавшие `opencode-cli` PID 18928 и `opencode-pty` PID 25124 не затрагивались; отдельный процесс встроенного OpenCode для свежего профиля не подтверждён.

## Итог и непроверенное

Первый запуск в новом профиле не достиг окна приложения. Поэтому не проверены создание начальных настроек, открытие чата и страницы настроек, обнаружение OpenCode 2.3.0 на этом профиле и штатное закрытие. Причину исключения установить не удалось; результат фиксирует сбой запуска, но не определяет, вызван ли он Portable-загрузчиком, окружением или приложением.

Существующий `test-results/portable-verification.json` описывает более ранний успешный прогон с другим профилем и не подтверждает этот сценарий первого запуска.
