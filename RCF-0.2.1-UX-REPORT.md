# RCF 0.2.1 — UX/UI refinement

Дата: 17 ноября 2026. Продолжение существующего RCF 0.2.0, OpenCode 2.3.0.

## Изменения по этапам

1. Изучены текущие настройки, темы, общие компоненты, виртуализованная история, GitPanel, ComposerControls, TaskControl, README, отчёты 0.2.0 и существующие проверки. Сохранены новые шапка, меню моделей, оригинальные изображения камня, модель хранения и архитектура OpenCode.
2. Все восемь страниц настроек используют компактные строки без разделителей между каждым параметром, ограничение контента 900 px и общий ритм секций. Добавлены `SettingsGroup` и `SettingsDisclosure` поверх существующих `SettingRow` и `Toggle`. Поиск раскрывает технические секции при переходе к найденному параметру.
3. Уплотнены Git Changes, меню разрешений и панель управления задачей. Изменены только представление и подписи; правила безопасности и процессы помощников/worktrees сохранены.
4. Добавлен Conversation Rail с виртуализованным списком маркеров, короткими текстовыми превью и точным переходом по ID сообщения.
5. Выполнены модульные, интеграционные и Electron UI-проверки на изолированных данных и локальных ответах провайдера.
6. Подготовлены production UI и упаковка Windows. Результаты проверки релизных артефактов указаны ниже.

## Git, разрешения и помощники

- Git: шапка 44 px, компактное переключение источника, меньшие отступы строк и панели. Сохранены diff, статистика, индексирование, ветки, commit, pull/push и PR. Длинные пути доступны через `title`, действия переносятся при недостатке ширины. Раздельные состояния: нет репозитория, чистая рабочая папка, нет diff задачи. Git автоматически не инициализируется.
- Разрешения: три строки с короткими описаниями, активной галочкой, клавиатурной навигацией и предупреждающим цветом Full Access. Сохранено отдельное подтверждение в main process. Файлы политик OpenCode не менялись.
- Управление задачей: вкладки «Рабочие копии», «Помощники», «Проверка изменений», «История задачи»; компактнее строки и отступы, вкладки переносятся. Сведения, статусы и запуск остаются реальными.
- Уже работающие меню `+`, каталога моделей, reasoning и проектов сохранены; повторная реализация этих компонентов не создавалась.

## Conversation Rail и длинная история

`src/ConversationRail.tsx` использует существующий `@tanstack/react-virtual`. Каждый пользовательский запрос имеет маркер. DOM содержит только видимую часть списка маркеров и небольшую область overscan, а не все сообщения. Превью — один ограниченный текстовый блок с датой; Markdown, изображения и полные сообщения в него не монтируются. Поддержаны фокус, Enter, стрелки, Home/End и Escape. На ширине области разговора до 940 CSS px rail скрыт, чтобы сохранить место для переписки.

Для сообщений за пределами начальной страницы добавлен узкий read-only IPC `conversationIndex`. Он проверяет принадлежность сессии через прежний `own`, запрашивает страницы OpenCode по 150 сообщений и возвращает только ID, время и до 320 символов текста пользовательских запросов после redaction. Индекс не запускает подготовку медиа и не расширяет кеш отображаемой истории. После переключения чата следующая страница индекса не запрашивается; поздний ответ игнорируется. Загруженные строки остаются авторитетными при замене/редактировании недавних сообщений.

Клик использует существующий механизм цели поиска по ID. Недостающая история подгружается через `olderMessages`; прокрутка начинается с виртуального индекса, затем корректируется по измеренной DOM-геометрии до стабильной позиции. Навигация отменяется ручным вводом прокрутки. Для восстановления сохраняются ID видимого сообщения и его реальное смещение относительно viewport; прежние числовые scroll drafts по-прежнему читаются. Это устраняет зависимость восстановления от оценочных высот ещё не загруженных строк.

## Ограничения

- Живые OAuth и запросы к платным/внешним моделям в этой работе не выполнялись. Существующие OAuth/API-настройки и формы сохранены; состояние «Настроен» не выдаётся за проверенную авторизацию.
- UI-тест истории охватывает 480 сообщений с разной высотой и кодом; отдельный многосуточный soak-test и замер времени старта Electron не выполнялись. Встроенный модульный тест нормализации 10 000 операций проходит. DOM rail и ленты ограничен виртуализацией; при первом открытии длинного чата чтение индекса всё же требует прохода по страницам OpenCode.
- Системная тема и новые операции очистки истории не добавлялись. Существующий ручной режим памяти и подтверждения удаления сохранены.
- Сохранено предупреждение Vite о стартовом JS chunk более 500 kB: примерно 744 kB до gzip. Новых зависимостей нет.
- NSIS не устанавливается поверх пользовательской системы в ходе тестов. Сохраняются прежние ограничения RCF 0.2.0, включая отсутствие изоляции ОС и отката файлов по checkpoint.
