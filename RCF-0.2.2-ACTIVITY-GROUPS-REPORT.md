# RCF 0.2.2 — сворачиваемые этапы активности

22 ноября 2026 года

Завершённый этап сворачивается в строку с количеством действий и их фактическими итогами. Текущие операции, ошибки и запросы подтверждения видны при свёрнутом этапе. Внутри этапа соседние чтения, файловые изменения, команды и распознанные проверки раскрываются отдельными группами. Ответ агента, смена агента или рабочей папки и завершение запуска отделяют этапы.

Кнопка «Скрыть завершённые действия» убирает успешные операции из переписки. «Показать действия» восстанавливает их с прежними настройками раскрытия. Режим показа и состояние раскрытия сохраняются для каждой сессии.

Операция изменения одного файла представлена одной строкой с относительным путём и статусом. Полный путь доступен в подсказке. Сохранённый патч раскрывается на месте, а параметры и вывод инструмента доступны по отдельной кнопке. Для путей вне рабочей папки отображается абсолютный путь. Статистика берётся из OpenCode, а отсутствие текстового патча явно обозначено.

| --- | --- |
| `npm run build` | Production-сборка и TypeScript прошли. Vite выдал предупреждение о JS-чанке больше 500 КБ. |
| `npm test` | 49 модульных тестов прошли. |

Проверены этап из 122 действий, независимые последовательные этапы, раскрытие групп, длинный вывод, diff, ошибки, подтверждение, остановка, потоковые обновления и восстановление режима показа и раскрытого diff после перезапуска. Живые сценарии выполнены на локальном OpenCode с тестовым провайдером. Категория «Проверки и тесты» присваивается известным инструментам проверок и явным командам. Остальные shell-вызовы отображаются как команды.
