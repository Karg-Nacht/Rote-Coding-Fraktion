# RCF 0.2.2 — лента действий и изменения файлов в переписке

22 ноября 2026 года

## Переписка

Вызовы OpenCode стали компактными строками внутри переписки. В строке видны действие, аргумент или команда, статус и длительность, когда движок её сообщает. Нажатие раскрывает подробности. Отдельное состояние ожидания подтверждения связано с запросом разрешения OpenCode. Мягкое изменение яркости работает у активных инструментов и отключается обеими настройками уменьшения движения.

Патчи из результата инструмента раскрываются рядом с этим вызовом. Для добавления, изменения, удаления и переименования показываются сведения, которые есть в результате OpenCode. Итоговые изменения всех файлов выводятся отдельной сводкой задачи. Встроенный просмотр использует общий компонент diff с номерами строк. Для больших патчей сначала показывается фрагмент, затем доступен полный сохранённый текст. Если движок не передал патч, интерфейс сообщает об этом.

Вывод команд начинается с короткого превью. Полный сохранённый вывод раскрывается отдельно, а длинные логи отображаются виртуализированным списком. Команду и вывод можно копировать независимо. Заголовки, списки, цитаты и таблицы Markdown получили более сдержанную типографику. Горизонтальный разделитель имеет высоту 1 CSS px. Блоки кода можно копировать, а подсветка распространённых языков загружается по запросу.

## Дополнительные правки памяти

- **Панель чтения.** Убраны рамка и линии в шапке и подвале. Добавлены мягкое скругление со стороны переписки, отступы между заголовком, метаданными и текстом, ограничение длины строки и независимая прокрутка. Кнопка редактирования находится внизу панели.
- **Редактор.** У диалога и поля ввода умеренные скругления. Поле выделяется оттенком поверхности, а при работе с клавиатуры виден контур фокуса. Счётчик и кнопки расположены непосредственно под текстом.
- **CustomSelect.** Меню получило мягкую поверхность, более широкие отступы пунктов и приглушённый бордовый выбор. Размещение учитывает границы окна, шапку диалога и область кнопок сохранения.

Живой OpenCode выполнил редактирование файла в папке без Git, успешную и ошибочную команды. Проверены подтверждение и остановка, обе настройки уменьшения движения и доступность патча после перезапуска. [Протокол](test-results/activity-timeline/verification.json) |
| `node scripts/custom-controls-ui.mjs`, `node scripts/memory-settings-ui.mjs` | Просмотр и редактирование памяти в обеих темах и трёх размерах окна. Проверены клавиатура, возврат фокуса, границы меню, сохранение, отмена, лимит текста, поиск, область памяти и данные после перезапуска. [Геометрия диалога и меню](test-results/activity-timeline/memory/verification.json) |

| `node scripts/rcf-diff-ui.mjs` | Полный Git diff конкретной задачи, навигация по файлам, проверка номера строки и добавление комментария в черновик. |
| `npm run test:edit`, `npm run test:desktop` | Редактирование последнего сообщения, отмена, вложения, сохранность файлов и запуск Electron 45.3.2 с локальным OpenCode. |

Прогон использовал изолированные профили и локальный тестовый провайдер. Патч отдельного действия доступен, когда OpenCode сохранил соответствующий результат. Командные изменения без такого патча могут быть видны в сводке задачи. Для полного diff свыше 300 000 символов предусмотрен текстовый режим, а за пределами набора поддерживаемых языков Markdown-код остаётся обычным текстом с копированием.
