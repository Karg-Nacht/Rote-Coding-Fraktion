# Меню чата

Открывается правой кнопкой на чате или кнопкой «Меню чата». Действие относится к выбранной строке, даже если открыт другой чат.

| Пункт | Поведение Rote Coding Fraktion |
| --- | --- |
| Переименовать | Меняет заголовок. Ctrl+Alt+R. |
| Закрепить / открепить | Перемещает чат в «Закреплено» или обратно. Ctrl+Alt+P. |
| Отметить непрочитанным / прочитанным | Сохраняет отметку с точкой и выделением названия. Открытие чата снимает отметку. Ctrl+Shift+U. |
| Проект | Меняет проект и рабочую папку чата. Файлы не перемещаются. |
| Раздел | Группирует чат в разделе боковой панели. Можно выбрать раздел, создать новый или убрать назначение. Рабочая папка не меняется. |
| Ответвить | Создаёт независимый чат с текущей историей в выбранном проекте. Источник сохраняется. Git-ветка, worktree и копия файлов не создаются. |
| Поделиться | Сохраняет текст переписки в Markdown через системный диалог. Перед передачей проверьте содержимое. Публичный сервис ссылок в RCF отсутствует. |
| Копировать | Название, ID или вся текстовая переписка, включая сообщения за пределами текущей страницы. Вложения и внутренние рассуждения в текстовый экспорт не включаются. |
| Открыть в новом окне | Отдельное защищённое окно того же приложения. Движок и профиль общие; выбранные чаты независимы. Закрытие одного окна не останавливает остальные. |
| Архивировать | Убирает чат из активных списков, сохраняя в «Архиве чатов». Оттуда его можно восстановить. Ctrl+Shift+A. |
| Удалить навсегда | После системного подтверждения удаляет историю, закрепление, отметки и черновик. Отмена ничего не удаляет. Файлы проекта сохраняются. |

Выполняющийся чат нужно остановить перед переносом, ответвлением или удалением.

[Официальное описание Codex](https://developers.openai.com/blog/mastering-codex-remote-for-engineering) подтверждает смысл ответвления как нового чата с общей историей, а архива — как организации без удаления. Скриншот задаёт состав меню. Точные варианты всех подменю официальная страница не перечисляет; таблица описывает реализацию RCF. Экспорт вместо публичной ссылки и отсутствие worktree у ответвления — явные ограничения.

Проверка: `npm run test:chat-actions`. Реальное приложение с отдельным профилем, два проекта, 320 сообщений, все 11 пунктов, сохранность ответвления после удаления источника, два окна, меню на 1440 и 780 px. Внешние модели и пользовательский профиль не используются. Отчёт: `test-results/chat-actions-verification.json`.
